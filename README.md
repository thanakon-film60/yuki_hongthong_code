# Yuki CardVault — คลังการ์ด Yu-Gi-Oh! + สแกนรูปเพื่อระบุการ์ด (ไทย)

เว็บแอป Python (Flask) สำหรับจัดการคลังการ์ด Yu-Gi-Oh! และ **สแกนรูปการ์ดเพื่อบอกชื่อเต็มภาษาไทย + สรุปเอฟเฟกต์ภาษาไทย** โดยไม่ต้องใช้ API key ใด ๆ — ทำงานออฟไลน์ทั้งหมด

> มาพร้อมชุดข้อมูลไทยสำเร็จรูป (`seed_cards.py`) ที่ระบุการ์ด 37 ใบจากรูปถ่ายของคุณไว้แล้ว
> รายการที่ลงท้าย **"(โปรดยืนยัน)"** คือใบที่ยังไม่มั่นใจ 100% — เปิดเว็บแก้ไขได้

## เริ่มเร็ว

```bash
pip install -r requirements.txt
python seed_cards.py   # โหลดการ์ดจากรูปถ่ายเข้าคลัง (รันครั้งเดียว)
python app.py          # เปิด http://127.0.0.1:5000
```

## หน้าบ้าน vs หลังบ้าน

| ส่วน | URL | ใครเข้าได้ | ทำอะไรได้ |
|------|-----|-----------|-----------|
| **หน้าบ้าน** (โชว์คอลเลกชัน) | `http://127.0.0.1:5000/` | ทุกคน | ดูการ์ด รายละเอียดเต็ม ราคา เอฟเฟกต์ (ดูอย่างเดียว) |
| **หลังบ้าน** (จัดการ) | `http://127.0.0.1:5000/login` | เจ้าของ (ใส่รหัส) | เพิ่ม / แก้ไข / ลบ / สแกนระบุการ์ด |

- เข้าหลังบ้านได้ **ทาง `/login` เท่านั้น** — หน้าบ้านไม่มีลิงก์ไปหลังบ้าน
- **รหัสผ่านเริ่มต้น: `yuki1234`** — เปลี่ยนได้โดยตั้ง environment variable ก่อนรัน:
  - Windows: `set ADMIN_PASSWORD=รหัสใหม่` แล้วค่อย `python app.py`
- API อ่าน (GET) เปิดสาธารณะ; API เขียน (POST/PUT/DELETE) ต้องล็อกอินก่อน (ไม่งั้นได้ 401)

## ทำอะไรได้บ้าง

- **คลังการ์ด** — เพิ่ม/แก้ไข/ลบการ์ด: ชื่อเต็ม, ชื่อย่อ, เอฟเฟกต์, หมวด, ความหายาก, ขนาด, รูป
- **ราคาหลายแหล่ง** — ใส่ราคาจากหลายที่ (ตลาดนัด, Shopee, เพื่อน ฯลฯ) เพื่อ**เปรียบเทียบ** พร้อมสรุป ต่ำสุด/สูงสุด/เฉลี่ย
- **วิเคราะห์อัตโนมัติ** — จัดระดับ**มูลค่า** 5 ระดับ และวิเคราะห์**ขนาด**เทียบมาตรฐาน 6.3 × 8.8 ซม.
- **สแกนระบุการ์ด** — อัปโหลด/ลากรูปการ์ด → ระบบจับคู่กับรูปในคลังด้วย *perceptual hash* → คืนชื่อเต็ม + เอฟเฟกต์ + ค่าความมั่นใจ

## วิธีระบุการ์ดทำงานอย่างไร (สำคัญ)

การ์ดเป็นรูปล้วน ไม่มีตัวอักษร → **OCR ใช้ไม่ได้** (OCR อ่านได้เฉพาะตัวหนังสือ) 
ระบบจึงใช้ **การจับคู่รูปภาพ** แทน:

1. ลงทะเบียนการ์ดแต่ละใบ **ครั้งเดียว** — อัปโหลดรูป + กรอกชื่อเต็ม + เอฟเฟกต์
2. ต่อไปถ่าย/อัปโหลดรูปการ์ดใบไหนก็ได้ → เทียบกับรูปที่เก็บไว้ (phash + dhash) → คืนใบที่ตรงที่สุด

> ยิ่งถ่ายชัด ตรงมุม ใกล้เคียงรูปต้นฉบับ ความมั่นใจยิ่งสูง

## REST API

| Method | Endpoint | คำอธิบาย |
|--------|----------|----------|
| GET | `/api/health` | สถานะระบบ |
| GET | `/api/cards?q=คำค้น` | รายการการ์ดทั้งหมด (+ วิเคราะห์) |
| GET | `/api/cards/<id>` | การ์ดใบเดียว |
| POST | `/api/cards` | เพิ่มการ์ด (multipart: name_full*, effect, prices JSON, image ...) |
| PUT | `/api/cards/<id>` | แก้ไขการ์ด |
| DELETE | `/api/cards/<id>` | ลบการ์ด |
| POST | `/api/identify` | **อัปโหลดรูป → ระบุการ์ด** (field: image) |
| GET | `/api/stats` | สรุปคลัง (จำนวน, มูลค่ารวม/เฉลี่ย) |

## การจัดระดับมูลค่า (จากราคาเฉลี่ย บาท)

| ระดับ | ราคา | ป้าย |
|------|------|------|
| 5 | ≥ 3,000 | หายากมาก / มูลค่าสูง |
| 4 | ≥ 1,000 | มูลค่าสูง |
| 3 | ≥ 300 | ปานกลาง |
| 2 | ≥ 50 | ทั่วไป |
| 1 | < 50 | ราคาถูก / พบง่าย |

## หมายเหตุทางเทคนิค

- ไลบรารีอ่าน/จับคู่รูป: **Pillow** + **ImageHash** (ออฟไลน์ล้วน ไม่ต้องต่อเน็ต ไม่ต้องมี key)
- ปรับความเข้มงวดการจับคู่ได้ที่ตัวแปร `MATCH_THRESHOLD` ใน `app.py` (ค่าเริ่มต้น 28 จาก 128)
- ทดสอบแล้ว: สร้าง/แก้/ลบการ์ด, วิเคราะห์มูลค่า+ขนาด, และ identify จับคู่ถูกต้อง
